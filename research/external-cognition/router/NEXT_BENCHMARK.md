# After representation calibration

The 96-slot campaign broadens model families and representation conditions while retaining two comparable problems. It does not yet supply broad task coverage. Do not mistake a large request count for a large independent problem sample.

If at least two families can complete the compact interface reliably, the next separately frozen experiment should include more generated seeds and a second task family requiring genuine decomposition. Candidate tasks are finite constraint problems with independent verifiers, dependency repair after changed premises, and distributed evidence reconciliation. Choose tasks with unambiguous mechanically checked outcomes and publish every selected instance before dispatch; participants receive only the public inputs.

Keep fresh single-model raw-facts controls and shared-state integration. Add a contribution-ablation control if the budget allows: the same integrator sees the problem and equally sized irrelevant peer messages. This separates useful authored state from extra context or extra inference. Compare solving after correct, erroneous, challenged, and stale peer contributions. Preserve stale proposals as potential forks and measure whether subsequent coherent revisions recover useful alternatives.

Report both success and resource cost. Matching or a useful partial success rate can demonstrate cooperative feasibility without an accuracy advantage. Define the benchmark denominator and useful threshold before execution. A claim of harder-problem capability needs problems demonstrably difficult for the same isolated model under comparable resources, not simply a lower context setting.

The external state may be machine-oriented. Deterministic validation should ensure structural integrity, provenance, dependencies, and reproducible transitions; it must not substitute a hidden mathematical oracle for participant reasoning. Distinguish freshly inferred relations from copied claims, and distinguish correct answers recomputed from full facts from answers causally dependent on shared contributions.
