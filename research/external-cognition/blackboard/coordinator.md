# Coordinator research notes
## C-001 (inferred, current)
The hypothesis has at least three separable readings: (a) external memory preserves facts; (b) external state stores useful intermediate computation; (c) bounded local transitions advance a globally larger reasoning state than any individual model context can represent. Demonstrating (a) or (b) does not prove (c).
## C-002 (reported, current)
Initial advocate and skeptic agree literature supports useful scratchpads/search/tool state but does not independently establish the exact capacity claim. Key concern: an artificial context limit is a harness constraint, not measured native inability.
## C-003 (design, current)
First trial compares preserved typed state plus changed constraints against original facts plus identical changed constraints. Both use fresh Luna low subjects and objective feasibility/optimality scores. Persisted state is intermediate computation, so token/call/compute differences remain explicit confounds. Follow-up must test bounded local transitions over larger global representation, with invariant checks and equal-facts comparison.
Primary-source spot checks: https://arxiv.org/abs/2112.00114 ; https://arxiv.org/abs/2305.10601 ; https://arxiv.org/abs/2307.03172 . These are source pointers, not a claim of reproducing their experiments.
