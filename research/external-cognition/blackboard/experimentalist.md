# Experimentalist — frozen pilot design

Date: 2026-10-01. Protocol: [experiments/protocol.md](../experiments/protocol.md), v1.1. No subject responses had been inspected when v1.1 was frozen.

## Operational question

Can a fresh model instance use a typed external state produced by an earlier fresh instance to update a multi-constraint solution after a context reset, compared with receiving all original facts again? The task is a maximum-value project subset under budget, mandatory inclusion, dependencies, pairwise conflicts, and a new project-unavailability fact. The state arm carries an explicit complete feasible-candidate ledger and its pre-delta optimum; Phase 2 must remove newly invalid sets and recompute. This is a substantive enumeration/update task rather than a lookup.

## Frozen execution

Two similarly sized, structurally matched fixtures use gpt-6-luna low, two fresh agents per arm/fixture, eight calls total. Both arms get identical Phase 1 calls. The state arm passes the exact Phase 1 artifact into a fresh Phase 2 context. The full-context control discards that artifact for Phase 2 and re-presents all raw problem facts plus the same delta. No context clipping. The output paths, prompt texts, exact fixture facts, and score rules are enumerated in the protocol and `experiments/prompts/`.

The fixed deltas were checked with an independent brute-force enumerator before subject launch: A makes G unavailable (five pre-delta feasible sets removed, pre-delta winner invalidated, optimum changes from A/E/F/G/H value 27 to C/E/F/H value 23); B makes D unavailable (four feasible sets removed, pre-delta winner invalidated, optimum changes from D/E/F/G value 26 to A/B/E/G value 22). This also corrected the first draft's B delta H, which was vacuous because H was infeasible already. Version 1.1 froze the nonvacuous fixtures and weights before subject output inspection; deltas were not adaptively selected after Phase 1.

The deterministic scorer checks each ledger row’s set, cost, and value; compares winner, source facts, availability/delta, removed and added sets, and before/after winner patch fields. `python experiments/score.py --self-check` passed: exact truth scored 100 in both phases/fixtures, an intentionally wrong winner scored below 100, and an intentionally corrupted candidate cost reduced the Phase 1 score. No subject runs are included in this design artifact.

## Validity threats, debate, and falsifiers

The advocate endorsed typed operational state and highlighted the risk that an explicit candidate ledger is unusually tailored to this task. The skeptic highlighted answer-bearing Phase 1 state, compute/resource mismatch, the need for post-freeze targets, and independent transition/invariant checks. The coordinator asked to preserve a full-context baseline and nonvacuous fixed deltas. The ledger is intentionally answer-bearing about the pre-delta problem: otherwise Phase 2 would receive merely reformatted facts and the design would not test whether intermediate derived state survives a context reset. But this makes transfer of useful Phase 1 computation part of the treatment. The protocol accordingly claims only value of a typed derived-state handoff for this task, not a pure memory-storage effect.

The full-context control sees equal source information and is not artificially restricted, but lacks the state arm’s explicit derived ledger. Total token/compute use may therefore differ despite both arms running Phase 1. Compare exposed token counts and label an advantage inconclusive as a representational advantage if resource use is materially higher. A same-schema rederivation control, equal-token opaque-notes control, shuffled/corrupted state, task-family variation, randomized post-freeze fixtures, and repeated samples would help isolate mechanisms; none fits this quick pilot. The native agent may read all workspace files, so procedural prompt-only concealment provides no genuine secrecy. Two matched fixtures, fixed synthetic inputs, and n=2 per condition cannot support population inference.

The predeclared failure rule: the state arm must beat the control on mean Phase 2 score and both state-arm Phase 2 outputs must satisfy feasibility; otherwise the expected benefit is not demonstrated. A material resource-use imbalance makes any apparent advantage inconclusive. A useful follow-up falsifier is a full-context baseline matched to the same typed ledger computation/token budget; if the state benefit vanishes there, evidence favors extra computation or format/task alignment over a special persistent-state benefit. Artificial context limits in any later experiment would only show performance under that restriction, not a native inability to hold the state.

## Methodological sources consulted

- Risko, E. F., & Dunn, T. L. (2015), “Storing information in-the-world: Metacognition and cognitive offloading in a short-term memory task,” *Consciousness and Cognition* 36, 61–74. Primary empirical article. The abstract reports experiments comparing internal-only memory with the option to externalize items and examines metacognitive decisions; it supports studying external storage as an experimentally manipulable aid, not claims about LLMs or constraint-state transitions. [PubMed record and DOI](https://pubmed.ncbi.nlm.nih.gov/26092219/).
- Kirsh, D., & Maglio, P. (1994), “On Distinguishing Epistemic from Pragmatic Action,” *Cognitive Science* 18(4), 513–549. Primary empirical/theoretical study: reports Tetris data and argues that some actions simplify cognition rather than directly advance the game goal. It motivates measuring whether an external manipulation aids computation; its interactive human setting differs from text-only model handoffs. [Publisher DOI page](https://doi.org/10.1207/S15516709COG1804_1).
- Risko, E. F., & Gilbert, S. J. (2016), “Cognitive Offloading,” *Trends in Cognitive Sciences* 20(9), 676–688. Review, not a primary experiment. It defines offloading as using action to change information processing demands and surveys memory/perception examples; it offers conceptual framing only. [DOI page](https://doi.org/10.1016/j.tics.2016.07.002).
- Clark, A., & Chalmers, D. (1998), “The Extended Mind,” *Analysis* 58(1), 7–19. Philosophical argument for active externalism, not an empirical demonstration. It offers historical conceptual background but no evidence for the present agent-performance claim. [Author-hosted text](https://www.consc.net/papers/extended.html).

## Known scoring and protocol boundaries

The exact scorer is deterministic and private-key separated from prompts, but agents can inspect the entire disk. The frozen protocol specifies a 100-point Phase 2 exact-match score and 100-point Phase 1 artifact diagnostic; ledger order is a separate diagnostic. It intentionally does not use significance tests. Report route, settings, all prompts/responses, token counts when available, malformed output, and deviations. Do not call artificial context restriction a demonstration of native capacity limits.
