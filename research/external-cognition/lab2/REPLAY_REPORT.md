# Campaign 1 deterministic replay audit

These runs replay preserved responses through the frozen campaign runtime. They are deterministic replays of already-existing outputs, not independent subjects and not live storage-effect controls. Both used `runs/campaign1/frozen_source/lab.py` with its sibling `core.py` (SHA-256: lab.py `9a71e7b7a41c25bdcbb54bc5d3f20c362184c860b012b8052e9050de2ba3e6c1`; core.py `c1594c72df661fd5f8d152a00ad73e9e9fa46abfb907b51491139acb0c962c3b`).

The checked JSON-backed replay used seed 1101, four stages, vector observations, and response IDs `replay-json-frozen-s0`, `replay-json-frozen-s1-repair`, `replay-json-frozen-s2`, and `replay-json-frozen-s3`. It submitted, in order, the preserved `vector_s0.raw`, `vector_s1_repair.raw`, `vector_s2.raw`, and `vector_s3.raw`; all four were accepted. Each locally emitted prompt was byte-identical to its frozen counterpart: `vector_s0_prompt.txt`, `vector_s1_prompt.txt`, `vector_s2_accepted_prompt.txt`, and `vector_s3_prompt.txt`. The repair feedback was deliberately not replayed: stage 1 emitted the ordinary stage-1 prompt, while its reused raw response was originally produced after the repair prompt. This output is therefore not a replay of the original stage-1 context.

The final decoded JSON state equals the preserved `vector_initial_state.bin` state. For that exact state, the JSON encoding is 691 bytes and the packed encoding is 266 bytes. Re-encoding the final state as packed produces bytes identical to `vector_initial_state.bin` (266 bytes).

The unchecked packed replay used response IDs `replay-unchecked-frozen-s0` and `replay-unchecked-frozen-s1-illegal`, submitting only `vector_s0.raw` and the original `vector_s1.raw`. Both were accepted, advancing to version 2 / stage 2. The stage-1 prompt matched `vector_s1_prompt.txt` byte for byte. An offline comparison against the frozen transition confirms the accepted stage-1 frontier is semantically wrong; the same preserved `vector_s1.raw` was rejected in the original checked run for parity. No later subject outputs were submitted to this run.

The primary evidence is [replay_evidence.json](runs/campaign1/replay_evidence.json); it contains exact response hashes, lengths, prompt hashes, receipts, state comparison, and frozen source hashes. Run stores are in `runs/campaign1/replay_json_frozen/` and `runs/campaign1/replay_unchecked_frozen/`. Preliminary same-named runs without the `_frozen` suffix were created before the frozen-source instruction; they are retained separately and are not evidence for this report.
