# Engine receipt

Implemented the lab2 core contract in `core.py` with deterministic seeded problem generation, an exact boundary-frontier transition, dynamic-programming oracle, versioned patches, suffix invalidation, canonical problem hashing, and checksummed JSON/packed codecs. The packed codec uses zlib over canonical JSON with a SHA-256 digest; neither codec uses pickle or evaluation. `replace_problem` returns a new state, preserves the computed prefix before `changed_stage`, increments the version, and updates the problem hash.

`tests/test_core.py` was written before `core.py`. Initial run from the lab2 directory failed at import with `ModuleNotFoundError: No module named 'core'`, confirming the absent implementation. A later red run found two incorrect expected frontier witnesses in the independent transition examples; corrected the fixtures from the parity equations before final verification.

Verification: `python -m unittest discover -s tests -p test_core.py -v` — 10 tests passed after the audit regressions were added. The tests compare generated problems at 1–4 stages and 20 seeds per size against independent exhaustive enumeration; cover transition ties, input immutability, stale and invalid patch rejection, unchecked acceptance without inference, arbitrary-precision cost, codec roundtrips and corruption detection, and updated-input suffix recomputation against a full frontier/oracle.

Diagnostics for checked bad transitions identify the class of issue (omitted boundary, invalid path, parity, local cost, or nonminimal/lexical witness) and do not reveal the expected frontier or oracle result. Invalid patches return the original state unchanged. Runtime end-to-end behavior and integration remain the runtime worker's responsibility. Limitations: problem validation allows nonnegative integer weights although generated tasks use 1–9; no resource limit is imposed on decoding compressed payloads.

Audit follow-up: a forged prior frontier with costs increased by 17 initially passed checked stage 2; the regression reproduced that finding before the fix. Checked patches now replay prior history transitions before accepting a new transition. The invalidation path verifies the prefix it reuses and rejects a forged prefix. The unchecked-patch regression still passes, as do the independent validator tests. The full lab2 suite then had 21 passing tests, one runtime error, and one skipped test. The runtime error was `UnboundLocalError` in `lab.py:304` when a rejected patch left `new_state` unassigned; reported to the runtime worker.
