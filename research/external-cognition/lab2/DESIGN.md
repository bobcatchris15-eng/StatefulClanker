## Scope

## Task family
Binary chain, each stage introduces x,y and receives previous boundary b. Legal (b+x+y)%2 == stage.parity. Local incremental cost wx*x+wy*y; ties lexicographic complete bit string. Initial b0=0 with cost0,bits empty. Frontier after each stage: best cumulative cost and witness bits for each feasible y0/1. Final required boundary0/1. Full task2N bits, deterministic generator reproducible seeds; independent brute-force oracle for small sizes, dynamic program for larger. Generated weights1..9 and parity0/1.
## Fixed APIs in core.py
- generate_problem(seed:int, blocks:int)->dict with schema_version1,seed,stages:[{index:int,parity:int,wx:int,wy:int}],final_boundary:int.
- initial_frontier()->list[{boundary:int,cost:int,bits:str}].
- frontier_step(stage:dict, frontier:list)->list same rows, sorted boundary, minimum cost then lexical bits. No shared boundary double-charge.
- oracle(problem:dict)->dict{cost:int,bits:str}, validates problem.
- initial_state(problem:dict)->dict{schema_version:1,problem_hash:str,version:0,next_stage:0,frontier:initial_frontier(),history:[]}.
- apply_patch(problem:dict,state:dict,patch:dict,verify:bool=True)->(new_state:dict,receipt:dict). patch exactly {base_version:int,stage:int,frontier:list}. verify true checks exact next frontier; verify false still schema/version/hash/shape checked, but does NOT correct/infer frontier. Invalid returns unchanged state and receipt accepted:false,issues:[...]; legal accepted increments version,next_stage and appends history snapshot {stage,frontier}. No mutation of passed state.
- replace_problem(problem:dict,state:dict,updated_problem:dict,changed_stage:int)->dict. Verify declared prefix unchanged, truncate affected history, preserve prefix frontier, increment version/update hash; recompute suffix through subsequent worker patches.
- encode_state(state:dict,codec:str)->bytes; decode_state(payload:bytes)->dict. codecs json and packed. packed opaque compressed/checksummed numeric/state encoding (safe no pickle/eval), deterministic reversible. Store must not fabricate computation.
- problem_hash(problem:dict)->str stable SHA256 canonical JSON.
