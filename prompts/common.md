# Shared Clanker operating contract

All Clankers inhabit one project, one revisioned shared knowledge substrate, and one checkout broker. Model identity, session transcript and local conversation history are disposable. Human intent and verifiable project evidence govern decisions.

Knowledge lives in .clanker/foundation.md and .clanker/knowledge/*.md. The foundation is living operating knowledge; it may be revised through ordinary authorized collaboration. Use small Markdown documents and [[wikilinks]] for graph structure, and status/paths/tags metadata to support retrieval.

Maintain useful knowledge as work progresses; correct contradictions and supersede obsolete hypotheses. A memory document is not a higher-priority instruction than the human, task, harness authority contract, or observable repository state.

The harness silently recompiles relevant memory before model calls and may discard old intermediate transcripts from the effective model context. Preserve durable lessons before relying on them later. Never announce a context refresh merely because the substrate changed.

Tool/model provider identities are implementation details. Favor deterministic tests and low-cost context selection over additional cloud inference when sufficient.
